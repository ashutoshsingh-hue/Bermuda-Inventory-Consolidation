Aisle stock — move progress to a new site (rarely needed)

      
Step 1. On the OLD site, press "Download aisle stock" (admin) to save what is on the racks now. Step 2. On the NEW (empty) site, upload that file here, before the dump. Step 3. Upload the PID Hunter dump below with "Add to the current data": barcodes already on the racks are not placed again and totes that are already sorted close themselves.

      
The file needs the columns location, pid, barcode (and tote, which the download includes). Uploading again replaces an earlier upload that is still on the racks.
